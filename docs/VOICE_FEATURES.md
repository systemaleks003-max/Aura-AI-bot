# 🎤 Голосовые сообщения и имитация живого общения

## Описание

Бот теперь поддерживает:
1. **Генерацию голосовых сообщений** (20% шанс для коротких текстов до 300 символов)
2. **Имитацию живого общения** с индикаторами "печатает..." и паузами между предложениями

## Компоненты

### 1. `src/services/tts.js`
Генерация голоса через Microsoft Edge TTS API.

**Функция:** `generateVoice(text, voiceName)`
- `text` — текст для озвучки
- `voiceName` — голос (по умолчанию `ru-RU-DariyaNeural` — женский русский)
- Возвращает путь к временному `.webm` файлу или `null` при ошибке

**Доступные голоса:**
- `ru-RU-DariyaNeural` — женский, дружелюбный (по умолчанию)
- `ru-RU-SvetlanaNeural` — женский, деловой
- `ru-RU-DmitryNeural` — мужской

### 2. `src/utils/human.js`
Имитация живого человека при переписке.

**Функция:** `humanReply(ctx, text)`
- Показывает индикатор "печатает..."
- Разбивает текст на предложения
- Рассчитывает время "набора" (40 мс на символ, макс 4 секунды)
- Отправляет по частям с паузами между предложениями

### 3. `src/queue.js`
Логика выбора формата ответа:
- **20%** — голосовое сообщение (только для текстов до 300 символов)
- **80%** — текст с имитацией набора через `humanReply()`

### Изменить шанс голосовых сообщений


- `0.2` = 20% шанс (можно изменить на `0.5` для 50%, `0.1` для 10% и т.д.)
- `300` = максимальная длина текста для голоса (символов)

### Изменить скорость набора текста
В файле `src/utils/human.js`, строка 13:
```javascript
const typingTime = Math.min(chunk.length * 40, 4000);
```

- `40` мс на символ (можно изменить на `30` для более быстрого набора, `50` для медленного)
- `4000` мс = макс 4 секунды на одно предложение

## Временные файлы

Голосовые файлы создаются как `temp_voice_<timestamp>.webm` в корне проекта и автоматически удаляются после отправки. Добавлены в `.gitignore`.

## Производительность

- Генерация голоса занимает ~1-3 секунды
- Не блокирует очередь (работает асинхронно)
- При ошибке генерации автоматически отправляется текст
- Лимит: только тексты до 300 символов (чтобы не создавать слишком длинные аудио)

## Отладка

Логи ошибок генерации голоса выводятся в консоль с префиксом `[VOICE ERROR]`:
```bash
docker logs -f flirtbot
```
